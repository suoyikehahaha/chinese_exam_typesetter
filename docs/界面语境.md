# 高中语文试卷排版界面语境

## 界面语言

结构节点指试卷结构树中的一个可选择对象，例如卷首、阅读材料、大题标题、具体题目或答案区域。

内容对象指结构节点内部可以独立选择、编辑和定位的最小语义单元，例如题干、单个选项、材料段落、作者、注释或出处。

属性检查器指左侧随当前结构节点和内容对象变化的编辑区域，集中显示内容、字体、段落、选择项、分页和整卷设置。

检查器按“内容、格式、整卷”三个标签显示。“内容”编辑文字与题型，“格式”调整当前对象，“整卷”影响整份文档，不受左侧选中题号的限制。常用区域仅保留自然分页／目标页数、四项页边距和“应用并查看”；卷名、科目、说明与文档类型收进默认折叠区域。高考真题模板固定内置并自动应用，卷首对象使用内置字体。

设置仍会自动更新；“应用并查看”会立即提交设置并定位待核对页。页边距等变化定位当前查看页，卷首信息变化定位首页。反馈区分等待、正在更新、画面已更新、画面无变化和失败，不把后台提交当作已显示完成。页面蓝框及页码标题只标记正在核对的位置，不改变导出样式。

只读预览指右侧由内部渲染器生成的连续 A4 页面。预览负责显示分页和定位，不承担文字编辑。

页面图片按视口和相邻页载入；适合宽度与页码跳转只改变显示，不改动文档。刷新和缩放保存当前页及页内位置，页数变化时夹取到仍存在的页。导出后底部提供文件与文件夹入口，保存草稿用于稍后继续结构化编辑，二者分别保留各自路径。

批量范围指将当前对象格式应用到当前题目、当前大题或整份试卷中的同类型对象。

提醒指分值缺失、总分差异、识别诊断和题量差异等信息。提醒显示在黄色提示条中，不阻止导入。导出前汇总提醒，并提供继续导出和返回检查两个选择。
