# 全国Ⅱ卷模板（2026）

内置高考真题模板依据用户提供的《2026年全国Ⅱ卷语文试题（模板）》中“注1—注13”的排版说明建立。从0.2.1起，启动、Word导入、草稿恢复和恢复默认都自动使用本模板，无需选择模板文件。模板正文仅供本地核验，不随源码分发；这些说明不会作为试题内容写入用户文档。旧草稿的手动对象格式仍然保留。

| 对象 | 模板要求 |
| --- | --- |
| 卷名 | 宋体三号（16磅），居中 |
| 科目名 | 黑体二号（22磅），居中 |
| 考试信息 | 宋体五号（10.5磅），首行缩进2字符 |
| 注意事项标题 | 黑体五号，顶格 |
| 注意事项正文 | 宋体五号，首行缩进2字符 |
| 大题标题 | 黑体小四号（12磅），顶格 |
| 阅读模块 | 序号和模块名称为五号宋体加粗，题数与分值为五号宋体常规字重 |
| 阅读提示 | 宋体五号，首行缩进2字符 |
| 材料 | 正文楷体五号、首行缩进2字符；标题黑体五号；作者楷体五号、居中 |
| 注释 | 仿宋小五号（9磅），首行缩进2字符 |
| 出处 | 仿宋五号，右对齐 |
| 题干 | 宋体五号，顶格 |
| 选项 | 宋体五号，竖向排列；文本之前1.5字符，悬挂1.7字符 |

页设置采用模板首节的A4纸张，上下25.4毫米、左右31.75毫米；页眉距边界15毫米、页脚距边界20毫米。选项使用Word“文本之前”的段落边界含义，不再把悬挂量叠加为3.2字符。由于1.7大于1.5，首行起点会比正文左边界略靠左0.2字符，这是模板参数的直接结果。

模板实际段落中存在多种行距，部分实际字号、缩进也与标注不一致。此预设优先落实明确标注，未规定的行距沿用基础配置。整卷、训练、参考答案均随内容自然分页，教师手动设定的行距与段距也会保留。

桌面界面不再显示模板选择或母版选择。正文使用内置规则，用户手动设置的对象格式最后应用，优先于默认值。兼容接口仍可读取历史预设，桌面使用流程统一采用内置模板。

预览与导出共用段落格式、局部文字格式和行距调节参数；导出不再自动进行第二轮行距校准。双列选项预览按两列显示；单行过长、超过整页高度时会提示预览按单列展开，DOCX仍保留双列。缺失原图或表格时明确提示恢复原件或重新导入。

内部预览用于校对内容、常用格式和分页趋势。Word/WPS行高、复杂表格精确尺寸及最终打印分页须以导出DOCX为准，不能把内部图片视为Word原生打印效果。
