# 高中语文试卷排版界面语境

## 界面语言

结构节点指试卷结构树中的一个可选择对象，例如卷首、阅读材料、大题标题、具体题目或答案区域。

内容对象指结构节点内部可以独立选择、编辑和定位的最小语义单元，例如题干、单个选项、材料段落、作者、注释或出处。

属性检查器指左侧随当前结构节点和内容对象变化的编辑区域，集中显示内容、字体、段落、选择项、分页和整卷设置。

只读预览指右侧由内部渲染器生成的连续 A4 页面。预览负责显示分页和定位，不承担文字编辑。

批量范围指将当前对象格式应用到当前题目、当前大题或整份试卷中的同类型对象。

提醒指分值缺失、总分差异、识别诊断和题量差异等信息。提醒显示在黄色提示条中，不阻止导入。导出前汇总提醒，并提供继续导出和返回检查两个选择。
