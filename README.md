# 高中语文试卷智能排版系统

当前发布版本为 0.4.5。软件面向高中语文试卷的结构识别、模板排版、实时预览和 DOCX 导出。

## 当前工作流程

1. 导入 `.docx` 或 `.doc` 试题，也可以把 Word 文件直接拖入窗口。
2. 系统识别卷首、阅读模块、材料、题目和题型，并生成可编辑的结构树。
3. 左侧修改题目内容、题型、分值、字体、字号、缩进、行距和目标页数。
4. 右侧内部预览随修改更新，点击结构树可以定位到相应页面。
5. 导出 DOCX，文件名默认采用导入文件名并添加“（排版）”。

## 办公软件兼容

DOCX 的读取、排版和导出由程序直接完成，启动和日常编辑不要求安装 Office 或 WPS。

导入旧版 `.doc` 时，程序按需检测 Microsoft Word 和 WPS Office。检测到 Word 时优先使用 Word，Word 不可用时尝试 WPS。两者都未安装时，软件仍可处理 DOCX，并会对 `.doc` 文件给出明确提示。

内部预览使用轻量页面渲染，不生成用户可见的 PDF 文件，也不会启动 PowerShell、Word 或 WPS 窗口。

## 可调整项目

- 全国卷默认排版预设与 Word 母版
- 客观题、主观题和语言文字运用动态题型
- 材料标题、作者、注释、出处和诗歌分行
- 选择项左缩进 1.5 字符、悬挂缩进 1.7 字符
- 主观题题干首行缩进 1.5 字符
- 目标页数，默认 8 页，系统在安全范围内调整段落节奏
- 题内混合字体、断句字母方框、作文三段式字体

## 开发运行

```powershell
python -m app.cli build samples\exam.json --config templates\layout.yaml --output output
python windows_launcher.py
```

## 边界说明

当前桌面导入范围为可编辑 Word 文档。扫描件 OCR、PDF 导入和 PDF 导出均不属于 0.4.5 的工作流程。表格、图片和原文字符装饰继续由 DOCX 原生对象保护逻辑处理。

## v0.4.5 发布说明

当前版本面向 Windows 10 和 Windows 11，支持将 DOCX 或 DOC 文件直接拖入软件窗口。
