# 高中语文试卷排版界面语境

## 界面语言

结构节点指试卷结构树中的一个可选择对象，例如卷首、阅读材料、大题标题、具体题目或答案区域。

内容对象指结构节点内部可以独立选择、编辑和定位的最小语义单元，例如题干、单个选项、材料段落、作者、注释或出处。

属性检查器指右侧可一键收起/展开的精细面板（启动时默认收起以提供超大沉浸 A4 纸面，点击顶栏“排版面板”、按 Ctrl+B 或激活待核对条目时展开），通过顶部分段切换器按“排版、整卷”两页显示。“排版”集中承载题目题型/分值、当前对象批量套用、缩进与段距、选择项专项排版及分页控制（基础字形、加粗、下划线、着重号、对齐与行距均直接归入纸面上方 Word 格式条与选区浮动栏）；“整卷”影响整份文档，常用区域保留四项页边距、快捷预设与“应用并查看”，卷首信息与文档类型默认折叠。高考真题模板固定内置并自动应用，卷首对象使用内置字体。

设置仍会自动更新；“应用并查看”会立即提交设置并定位待核对页。页边距等变化定位当前查看页，卷首信息变化定位首页。反馈区分等待、正在更新、画面已更新、画面无变化和失败，不把后台提交当作已显示完成。页面蓝框及页码标题只标记正在核对的位置，不改变导出样式。

主舞台默认呈现“排版编辑”仿真 A4 富文本直编视图，支持像 Word 一样直接点选、单段局部拖选或跨多段拖选文字并原地改字，配合顶部单行快捷格式条和选区上方自动弹出的浮动迷你格式栏设定字体、字号、加粗、下划线、着重号、对齐、行距与清除局部格式，所有操作均直写底层结构化数据并与大纲、属性检查器实时双向联动。点击顶部分段按钮可一键切换至“分页预览”只读 A4 连续页面舞台或“打印校对”，核对自然分页与精确打印版式。

页面图片按视口和相邻页懒加载高清缩放；适合宽度与页码跳转只改变显示，不改动文档。刷新和缩放保存当前页及页内位置，页数变化时夹取到仍存在的页。导出后顶部滑出结果横幅提供文件与文件夹入口，保存草稿用于稍后继续结构化编辑，二者分别保留各自路径。

批量范围指将当前对象格式应用到当前题目、当前大题或整份试卷中的同类型对象。

提醒指分值缺失、总分差异、识别诊断和题量差异等信息。无提醒时不占界面空间；存在提醒时在左栏以可折叠待核对抽屉呈现，点击即可跳转定位，不阻止导入。导出前汇总提醒，并提供继续导出和返回检查两个选择。
