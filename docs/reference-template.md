# 全国Ⅱ卷模板（2026）

此预设依据用户提供的《2026年全国Ⅱ卷语文试题（模板）》中“注1—注13”的排版说明建立。模板正文仅供本地核验，不随源码分发；这些说明不会作为试题内容写入用户文档。原“全国卷”预设保持兼容，选择新预设后应用下表规则。

| 对象 | 模板要求 |
| --- | --- |
| 卷名 | 宋体三号（16磅），居中 |
| 科目名 | 黑体二号（22磅），居中 |
| 考试信息 | 宋体五号（10.5磅），首行缩进2字符 |
| 注意事项标题 | 黑体五号，顶格 |
| 注意事项正文 | 宋体五号，首行缩进2字符 |
| 大题标题 | 黑体小四号（12磅），顶格 |
| 阅读模块 | 序号和模块名称为五号宋体加粗，题数与分值为五号宋体常规字重 |
| 阅读提示 | 宋体五号，首行缩进2字符 |
| 材料 | 正文楷体五号、首行缩进2字符；标题黑体五号；作者楷体五号、居中 |
| 注释 | 仿宋小五号（9磅），首行缩进2字符 |
| 出处 | 仿宋五号，右对齐 |
| 题干 | 宋体五号，顶格 |
| 选项 | 宋体五号，竖向排列；文本之前1.5字符，悬挂1.7字符 |

页设置采用模板首节的A4纸张，上下25.4毫米、左右31.75毫米；页眉距边界15毫米、页脚距边界20毫米。选项使用Word“文本之前”的段落边界含义，不再把悬挂量叠加为3.2字符。由于1.7大于1.5，首行起点会比正文左边界略靠左0.2字符，这是模板参数的直接结果。

模板实际段落中存在多种行距，部分实际字号、缩进也与标注不一致。此预设优先落实明确标注，未规定的行距沿用基础配置；全卷的8页是有限调节目标，不是模板规定的绝对结果。需要保留自然行距时，把目标页数设为0。部分板块组合的限时训练默认自然分页。

“选择母版”用于保留Word资源和页眉页脚，不会自动推断任意Word文档的正文格式体系。正文规则来自所选排版预设。用户手动设置的对象格式最后应用，优先于预设。

内部预览用于校对内容、字体和分页趋势。母版页眉页脚、Word/WPS行高与最终打印分页须以导出DOCX为准，不能把内部图片视为Word原生打印效果。
