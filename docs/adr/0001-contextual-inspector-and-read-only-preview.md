# 1. 左侧属性检查器与右侧只读预览

Date: 2026-08-07

## Status

Accepted

## Context

早期版本尝试在 A4 预览页直接编辑文字。页面重新分页时容易发生抖动，图像、表格和字符装饰的显示也容易与导出结果产生差异。用户需要清晰的编辑入口，同时希望结构树点击后可以准确定位到预览位置。

## Decision

采用左侧结构树与上下文属性检查器作为唯一编辑入口。结构节点内部继续拆分为题干、选项、材料段落、作者、注释、出处等内容对象。右侧使用内部渲染生成的连续 A4 只读页面，并通过内容对象定位键滚动到对应位置。

## Consequences

编辑操作具有明确范围，可以减少整块内容被误改的风险。预览能够保持稳定，并继续展示图片、表格和字符装饰。定位精度依赖结构化对象与预览锚点的一致性，需要通过多类试卷持续回归。
